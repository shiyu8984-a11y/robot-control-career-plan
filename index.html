五条核心结论

1 · 单年院线不可信，真正要看「波动类型」

初版只引 2026 一年，导致判断失真。补查近三年后，各校分化为两种形态：

  • 单调上涨型（浙大 +68/4 年、深大 +93/4 年、苏大 +46/3 年）——区位与热度驱动，可外推
  • 剧烈摆动型（东南 367→315→310、华理 370→338→324）——报考博弈驱动，单年预测几乎无效

这也是本报告与你手上两份原材料的最大分歧点。

2 · 「211 是挤压带会涨」并不成立

初版认为 211 会普遍上行。核实后：南航专硕三年在 338–345 徘徊（基本不动），华理反而从 370 降到 324 再反弹。真正在涨的是「区位稀缺 + 名额少」的那几所，而非整个 211 群体。

结论修正为：涨不涨看该校的供需，不看它是不是 211。

3 · 城市选择：产业规模与「隐含增速」比口号更可信

用官方目标反推隐含年增速（这是本报告自建指标）：苏州 1395 亿→2027 目标 2000 亿（+12.8%/年）最扎实；佛山 600 亿→2027 目标 2000 亿（+49%/年）最激进、可信度最低。

判断原则：目标越激进，越要打折看。

4 · 房价全线下行，但一线门槛未实质降低

2025 年 12 月 70 城二手住宅同比：一线 −7.0%（北京 −8.5、深圳 −5.4）、二三线 −6.0%。价格在跌，但深圳成交价仍约 5.9 万/㎡，按控制岗起薪仍难在十年内独立攒够首付。

改善最明显的是苏州 / 无锡 / 常州：工资高、房价 1.1–1.5 万区间。

一句话方案（可执行）

杭电（保底，327 分 / 240 名额）+ 南航或南理工（主攻，约 360 线）+ 同济（冲刺，365 已确认），统一按「数一 + 英一 + 自动控制原理」复习以最大化科目兼容；就业落点优先苏州 / 无锡 / 常州，前沿经验可去深圳 / 上海取 3–5 年再回撤。

1.3 城市分档结论

T1 · 首选

苏州 / 深圳 / 上海

苏州：伺服+减速器双核心零部件，房价仅 1.46 万，性价比第一。
深圳：产值 2012 亿全国第一、企业 7.4 万家，运控/嵌入式岗位最密，但房价 5.9 万。
上海：工业机器人产量占全国 12% + 全国首个国地共建人形创新中心，整机与资本强。

选择的本质是：苏州换性价比，深圳换密度，上海换天花板。

T2 · 特色对口

杭州 / 南京 / 常州 / 无锡 / 佛山

杭州：宇树全球出货第一，算法岗薪资全国最高（25–55K），但全市规上产值仅 148.5 亿——高薪、高弹性、体量小。
南京：埃斯顿国产工业机器人出货第一 + 智能制造装备营收 2898 亿。
常州：本体产量占全国约 1/4。无锡：信捷伺服/PLC。佛山：美的库卡重载市占 41.5%。

T3 · 潜力或细分

广州 / 东莞 / 合肥 / 武汉 / 成都 / 宁波 / 北京

广州偏智能装备；东莞拓斯达 + 3C 集成；合肥优艾智合总部 + 蔚来；武汉完整度 85% 但规模未披露；成都 AI+机器人体量大但控制岗密度待验证；宁波三大件全但规模仅约 80 亿；北京研发强、制造外迁，对硕士而言是"高门槛高天花板"。

② 真正的风险不是"行业不增长"，而是"产能过剩 + 订单不足"：2026 已出现满产 5.2 万台 vs 交付千台级的错配。这意味着2027–2028 可能出现一轮初创出清，就业市场会从"抢人"转向"挑人"。

③ 对你的含义：你 2028 年毕业，恰好卡在"出清期"与"规模化期"之间。抗风险策略是选"工业基本盘"（伺服/运控/工业机器人集成），而不是纯"人形概念"岗位——前者在悲观情景下仍有需求，后者会随融资收缩。
